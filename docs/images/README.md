# README 渲染图

当前根 README 的功能配图仅使用下列手工绘制的 SVG 产品示意图，不使用应用截图；顶部应用图标继续使用公共品牌资源：

- `deck-overview.svg`：Deck 导航、代码、链接、多文件卡片。
- `category-workspace.svg`：分类、颜色、脚本编辑、样本测试与控制台。
- `lan-sync.svg`：虚构设备列表、局域网可见与同步范围。

## 隐私约定

不从系统剪贴板、历史数据库、窗口或真实截图提取展示内容。文件名、设备名和脚本均为固定虚构样例；链接仅使用保留的示例域名 `example.com`，不展示真实路径、IP、用户名、配对码、令牌或网络信息。

SVG 不含脚本、外链字体、外部图片、追踪链接或嵌入式位图。图标使用内联矢量路径；字体由阅读端的系统字体回退。窗口布局按仓库当前代码概括，配图不是逐像素的跨平台效果承诺。

本目录原有 PNG 是历史资源，当前 README 不再引用。此调整不删除历史文件，也不意味着已经完成对历史图片或 Git 历史的隐私审计。

## 本地检查

可使用 `rsvg-convert` 将 SVG 栅格化为临时 PNG 做排版检查；不要将真实应用截图覆盖到这些资源上。

```bash
rsvg-convert -o /tmp/clipdeck-deck-preview.png docs/images/deck-overview.svg
```
