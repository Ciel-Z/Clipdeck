# ClipDeck Windows 第 0 阶段技术验证

这个程序是独立保留的早期技术验证工具，**不是**当前产品客户端。
当前 Windows 客户端从 `windows/CMakeLists.txt` 构建，运行和安装说明见
[根 README](../../readme.md#从源码构建)。本说明仍随 Spike 测试包分发，用于验证以下三项：

1. Win10 上无边框窗口的“模糊背景 + 24px 圆角 + 阴影”能做到什么程度
2. 全局热键呼出 → Deck 收到键盘 → 焦点还给原应用 → 自动粘贴，是否可靠
3. QML 横向卡片带在 100 张卡片下能否保持 60fps

所有观察都写入 `%LOCALAPPDATA%\ClipDeckSpike\spike-log.txt`（路径也会出现在日志的第一行）。测试结束后请把这个文件和截图一起发回来。

## 运行

1. 解压 `ClipDeckSpike.zip`，双击 `clipdeck-spike.exe`。程序只在托盘区显示图标（Win10 默认会收进 `^` 溢出区）。
2. 呼出：`Alt+Shift+V`；如果这个组合已被占用，程序会退而注册 `Ctrl+Shift+V`，实际注册的组合显示在 HUD 第三行。也可以左键点击托盘图标呼出。
3. 换渲染后端：在命令行里运行 `clipdeck-spike.exe --rhi=d3d11`（默认）、`--rhi=opengl` 或 `--rhi=software`。

## 按键

| 按键 | 作用 |
|---|---|
| F1 | 亚克力 + `SetWindowRgn` 圆角（没有系统阴影） |
| F2 | 经典模糊 + `SetWindowRgn` 圆角 |
| F3 | 亚克力，直角，DWM 阴影 |
| F4 | 不用系统模糊；QML 绘制抗锯齿圆角和阴影 |
| `+` / `-` | 调整亚克力着色透明度（每次 16，HUD 显示当前值） |
| F5 / F6 | 开关卡片阴影 / 开关卡片圆角遮罩（用于对比性能） |
| F7 | 拖动调整高度时是否保持亚克力（默认改用经典模糊） |
| F8 | 固定 Deck：失去焦点时不收起，方便截图 |
| F9 | 跑一次滚动基准测试（来回各 6 秒），结果显示在 HUD 并写入日志 |
| F10 | 隐藏 HUD，用于截图对比 |
| ← / → | 选择卡片 |
| Enter / 双击 | 粘贴；按住 Shift 双击为纯文本粘贴 |
| 按住 Ctrl | 显示 1–9 序号；Ctrl+1…9 快速粘贴 |
| Esc | 收起 |
| Ctrl+Q | 退出 |
| 顶部 18px | 上下拖动调整高度 |

额外检查：
- 用 `Alt+Shift+V` 呼出后，粘贴到记事本和 Word 时，**菜单栏有没有被激活**（Alt 抬起残留），开始菜单有没有弹出。
- 呼出 Deck 后点击桌面或其他窗口，Deck 是否自动收起（F8 固定时不应收起）。
- 在 Deck 打开时用另一个程序复制内容，再按 Enter：日志应记录 `result=Cancelled`。

日志中每次粘贴都有一行 `[paste] result=...`，包含目标进程、完整性级别、等待焦点的毫秒数和发出的按键。
