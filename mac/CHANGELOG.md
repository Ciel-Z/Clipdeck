# ClipDeck macOS 更新说明

## 未发布

- 图片预览框按原图宽高比与旋转方向动态调整，设置尺寸边界，使超大图片保持适中的预览大小。
- 图片读取优先于文件 URL 过滤，兼容微信照片复制时同时提供图片和临时文件 URL 的情况，并支持直接读取图片文件 URL。
- 补充 JPEG、HEIC、WebP、GIF 等剪贴板图片表示，转换为 PNG 时应用原图方向信息并保留容量与像素限制。

- 优化分类 JavaScript 编辑体验：新增行号、横向滚动、自动缩进、Tab/Shift-Tab 缩进和 `Command + /` 行注释。
- 新增可展开的大编辑窗口，将脚本、测试输入、运行结果和 `item` 可用字段说明集中展示。
- 分类设置内的脚本编辑区增高，并持续显示行数、字符数和常用快捷键提示。
- 补充标准“编辑”菜单，使脚本编辑区、规则测试区及其他文本输入控件支持复制、剪切、粘贴、全选、撤销和重做快捷键。
- 从 ClipDeck 设置窗口唤出 Deck 时保留设置窗口和应用前台状态；选择卡片后可直接粘贴回此前聚焦的设置输入区域或展开编辑窗口。
- 重构展开式 JavaScript 编辑页：移除重复的测试、保存和完成操作，改为分区工具栏及“取消 / 保存并完成”；限制测试输入高度，并让字段说明独立滚动。
- 规则测试支持捕获 `console.log/info/warn/error/debug`，按级别和调用顺序显示多参数、数组及对象，并在控制台末尾显示匹配结果或运行异常。

## 0.1.0 (Build 4) — 2026-08-26

- 外接鼠标在卡片区域滚动纵向滚轮时，改为平滑横向滚动 Deck 内容卡片。
- 保留触控板原生横向滚动，并避免影响分类栏和预览/编辑器的纵向滚动。

## 0.1.0 (Build 3) — 2026-08-26

- Deck 改用可直接接收键盘事件的非激活式 `NSPanel`，修复 DMG/Release 运行时从菜单栏唤出后没有焦点的问题。
- 移除对 `applicationDidBecomeActive` 回调的依赖，保留原前台应用的激活状态，避免打包版本与 Xcode 调试版本行为不一致。
- 新增 Deck 必须可成为 key window 且使用非激活式面板的回归测试。

## 0.1.0 (Build 2) — 2026-08-25

### Deck 与菜单栏

- 修复菜单栏左键无法稳定唤出 Deck、其他应用处于前台时不显示，以及唤出后无法接收键盘操作的问题。
- 菜单栏图标改用 ClipDeck SVG 应用图标，并修复 Xcode 重新运行后图标为空的问题。
- 保留按住 Command 拖动菜单栏图标调整位置的系统行为。
- 支持 `Command + ,` 打开设置；从“添加分类”进入时直接显示分类设置。
- Deck 获得焦点时可直接使用卡片菜单快捷键，`Command + O` 使用默认浏览器访问链接。

### 搜索、预览与编辑

- 搜索支持关键词与分类双重筛选；首次输入自动切换至历史，后续输入不再重置分类。
- 搜索框支持粘贴、中文输入法组合输入，并在退格删除全部内容后自动收起。
- 搜索已有内容时，左右方向键用于切换结果卡片。
- 文本预览支持自动换行；上下方向键可平滑滚动预览内容。
- JSON 编辑新增格式化功能，分类 JavaScript 编辑器支持 `Command + A` 全选。
- 图片旋转改为保存角度并在渲染、预览和粘贴时应用，避免重复编码图片数据。

### 卡片操作与反馈

- 普通退格键不再删除卡片，使用 `Command + Delete` 快速删除，并在右键菜单显示快捷键。
- 新增复制和粘贴反馈音效。
- 优化色彩识别规则，降低验证码、纯数字等内容被误识别为颜色的概率。
- 同一天或近 24 小时内再次复制已成功获取图标的链接时复用已有元数据。

### 数据与性能

- 内容使用 SHA-256 摘要和数据库索引，在近 24 小时窗口内高效判断重复内容。
- 历史过期以最近一次复制时间为起点；缩短保留期限时显示删除确认警告。
- 调整保留历史刻度与选中值显示，并修复清理后占用空间反而增大的问题。
- 启动时优先加载分类和最近 20 张卡片，其余历史在后台继续加载。
- 新复制内容先即时生成卡片，再在后台完成落库和 JavaScript 分类；剪贴板检测间隔由 0.4 秒缩短为 0.2 秒。
- 合并分类状态数据库写入，避免 JSON 等内容等待多次事务后才显示。

### 稳定性

- Deck 显示时 `Command + Q` 可直接退出应用。
- 修复搜索输入法丢字、焦点竞争导致键盘无响应或卡住等问题。
- 增加重复内容、保留期限、图片角度、快捷键与即时卡片更新相关测试。
